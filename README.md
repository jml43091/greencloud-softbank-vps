## IP 质量与流媒体：能干什么、不能干什么

软银线的 IPv4 是机房广播 IP，注册地在德国、使用地在日本（这是广播 IP 的常见现象），风险评级低到极低，黑名单 0 条。但流媒体解锁比较拉胯：Disney+ 和 Reddit 被屏蔽，日本本土流媒体基本全灭。ChatGPT、TikTok、YouTube、Netflix 自制剧在实测中是可用状态，Meta AI 也能用。

做邮件服务器的可以记两个细节：IPv4 的 25 端口开放，实测与 Gmail、Outlook、QQ 邮箱等主流服务商连通；IPv6 的 25 端口则被封。要在软银机上发信，走 IPv4。

硬件本身不差：EPYC Milan CPU，NVMe 存储顺序读写能到 1.5–3.6 GB/s，Geekbench 5 单核 825。跑轻量 Web 服务、开发测试环境绰绰有余。随机 4K 读写偏弱，数据库类应用要有心理预期。

## 三个容易踩的坑

**第一，CPU 有 30% 平均使用率限制。** 这是写在官方条款里的，很多测评只带过一句。原文是：KVM VPS 的 CPU 核心为共享（VDS 套餐除外），平均使用率不应超过 30%，每 24 小时允许 10 分钟冲到 100%；长期占满一个核心、影响其他客户的负载，官方可能降速、重启、停机甚至暂停服务。也就是说，宣传页上的“2核”不能当独占 2 核用。跑持续性高负载任务（爬虫、编译农场、长期满载转码）的，这台机器不合适，要么看绿云的 VDS 产品线，要么换别家。
